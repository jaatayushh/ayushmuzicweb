Developer / CLI Launch

Run directly using Gradle or package UberJar

AyushMuzic is built on Compose Multiplatform. Launch directly via PowerShell:

# Run Desktop application
.\gradlew.bat :desktopApp:run

# Build Standalone Windows MSI
.\gradlew.bat :desktopApp:packageMsi
  • Native libmpv decoding without video lag
  • Keyboard shortcuts for play/pause and skip
  • Full multi-column widescreen UI layout

Linux (.tar.gz / AppImage)

Ubuntu, Fedora, Arch, Debian, openSUSE

AyushMuzic runs natively on Linux through Compose Multiplatform with PulseAudio and PipeWire support. 

# Build or package for Linux
./gradlew :desktopApp:packageReleaseUberJarForCurrentOS

Frequently Asked Questions

Got Questions? We've Got Answers

Clear answers about AyushMuzic, installation, privacy, and feature sets.

AyushMuzic is a free, open-source streaming client architected with Compose Multiplatform. It streams audio streams from YouTube and YouTube Music without ads, without tracking, and without forcing you to log in with a Google account. It is 100% free under the GNU General Public License v3.0 (GPLv3).

No! AyushMuzic works out of the box in guest mode. Its local playback engine builds personalized recommendation carousels, "Jump back in" shelves, and similar song radios entirely on your device without storing your data in the cloud. You can optionally log in if you wish to sync your existing YouTube Music playlists.

The Listening Receipt is computed completely offline on your device using your Room database playback stats. It generates a stylized thermal receipt with authentic paper typography, barcode seed, item count, and duration. Your listening history is never transmitted to any third-party analytics servers.

Simply download the AyushMuzic-v1.0.8-Setup.msi installer from our Download section. Run the installer and follow the prompt. It automatically configures the desktop application, start menu shortcut, and the native libmpv hardware-accelerated audio engine.

AyushMuzic provides native desktop packages for Windows 10/11 (via .msi installer), as well as macOS (Universal DMG for Intel and Apple Silicon) and Linux (tarball and AppImage).

Yes! Tracks can be cached to local storage for offline playback so you can listen seamlessly without requiring an internet connection. You can also import playlists from Spotify or sync them with YouTube Music.

SponsorBlock is an open-source crowdsourced database that catalogs sponsor segments, intros, outros, and non-music dialog in music videos. AyushMuzic queries this database automatically to seamlessly jump over sponsors so you hear only uninterrupted music.
